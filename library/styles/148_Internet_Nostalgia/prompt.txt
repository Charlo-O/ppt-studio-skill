Design Style:

GeoCities、

WordArt、
ClipArt、
個人ホームページ文化から着想を得た

Visual Rules:
- Use rainbow gradients without restraint.
- Mix unrelated decorative elements freely.
- Decorate every slide with emojis, clip art, and stickers.
- Use multiple decorative fonts in the same presentation.
- Apply glow, outlines, and WordArt effects to headings.
- Include oversized animal photographs throughout.
- Allow inconsistent layouts and color combinations.
- Recreate the feeling of a 2002 personal homepage.

Avoid:
- Swiss Design
- Minimalism
- Editorial layout
- Material Design
- Glassmorphism
- Modern UI
- Consistent typography
- Professional presentation design
