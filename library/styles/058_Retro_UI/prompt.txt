Design Style:
Name: "Retro UI"

Concept: >
1990年代のWindows UIを
現代的なミニマルデザインで再構成した
ソフトレトロプレゼンテーション。

パステルカラー、
太いアウトライン、
ウィンドウ風カードレイアウトを用い、
親しみやすく整理された情報設計を実現する。

- Clean
- Organized
- Educational
- Playful
- Minimal
- Professional

Accent:

Style: Rounded Sans

Body:
Style: Clean Sans
Weight: 400-500

Illustration:

Style:
Soft UI Icons

Objects:
- Mouse
- Window
- Folder
- Pencil
- Notification
- Rating
- Button

Layout:

Structure:
- Window UI frames
- Large headline
- Card-based content
- Strong hierarchy
- Wide whitespace

Effects:

Borders:
Thick black outlines

Shadows:
Hard offset shadow

Gradients:
None

Rules:
- Use soft pastel accents
- Keep interfaces simple
- Maintain retro computer aesthetic
- Avoid bright neon colors
- Prioritize readability
- Use generous spacing
- Suitable for education, consulting, workshops, AI literacy, and business presentations
