Design Style:

Microsoft WordArt、
GeoCities、

Visual Rules:
- Mix unrelated colors without restraint.
- Use different background styles across slides.
- Combine decorative fonts freely.
- Place cute animal photos throughout the presentation.
- Apply exaggerated text effects.
- Allow inconsistent layouts between slides.
- Create a nostalgic early-2000s PowerPoint feeling.
- Prioritize humor over visual consistency.

Avoid:
- Minimalism
- Swiss Design
- Material Design
- Glassmorphism
- Editorial layouts
- Clean typography
- Consistent grids
- Modern presentation aesthetics
