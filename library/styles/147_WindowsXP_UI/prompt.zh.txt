设计风格:
名称: "Windows XP 界面"

设计理念: >
Windows XP、
视窗98、
经典的图形用户界面，
弗鲁泰格航空、
早期的互联网，
复古电脑桌面，
受到 2000 年代软件 UI 的启发
怀旧的桌面界面呈现。

不是使用幻灯片作为解释材料，
旧Windows电脑桌面
软件画面，
复古操作系统，
被构建为计算机杂志的专题页面。

留白:
密度: 中等

视觉规则:
- 每张幻灯片都应该类似于旧的 Windows 桌面。
- 将内容放置在浮动应用程序窗口内。
- 始终使用经典的蓝色标题栏。
- 保持 Windows XP Bliss 景观在幻灯片中可见。
- 添加鼠标光标和经典按钮作为装饰性 UI 元素。
- 对话框内的框架信息。
- 保持 2000 年代初期怀旧的桌面软件外观。
- 使用微妙的像素风格装饰图形。

避免事项:
- 玻璃拟态
- 现代平面仪表板
- 移动用户界面
- 极简的公司布局
- 重梯度
- 霓虹色
- 未来界面
- 当代网页设计
