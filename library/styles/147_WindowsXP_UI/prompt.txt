Visual Rules:
- Every slide should resemble an old Windows desktop.
- Place content inside floating application windows.
- Use classic blue title bars consistently.
- Keep the Windows XP Bliss landscape visible across slides.
- Add mouse cursors and classic buttons as decorative UI elements.
- Frame information inside dialog boxes.
- Maintain a nostalgic early-2000s desktop software appearance.
- Use subtle pixel-inspired decorative graphics.

Avoid:
- Glassmorphism
- Modern flat dashboards
- Mobile UI
- Minimal corporate layouts
- Heavy gradients
- Neon colors
- Futuristic interfaces
- Contemporary web design
