Visual Rules:
- Every slide should resemble a Windows 98 desktop application.
- Present information inside classic software windows.
- Use blue title bars and gray interface frames consistently.
- Include menu bars, taskbars, and browser controls.
- Keep all interface elements pixel-inspired and low-tech.
- Organize content as if navigating desktop software.
- Maintain the nostalgic feeling of late-1990s operating systems.
- Prioritize UI authenticity over modern aesthetics.

Avoid:
- Glassmorphism
- Material Design
- Flat mobile UI
- Modern browser styling
- Rounded cards
- Large gradients
- Neon effects
- Contemporary dashboard layouts
